# 人物卡片出图小工具（char-card-studio）设计

**日期：** 2026-09-17  
**状态：** 待用户审阅  
**范围：** 独立 Vite + React 小应用；本地侧栏快改；先导出 16:9 PNG

---

## 1. 目标

做一个与主站**完全脱钩**的本地小工具，视觉对齐落地页「人物 Teaser」，用于：

- 在浏览器里用**侧栏**快速改姓名、简介、立绘等
- **一键导出 PNG**（第一期固定 **1920×1080 / 16:9**）
- 产出图给社交媒体或设计使用

**不做（第一期）：**

- 回写主站文案 / 资源
- 组织 Tab、多人物轮播与切换动效
- 竖图导出（预留第二期）
- 账号、云同步、后端

---

## 2. 用户流程

1. `npm install` → `npm run dev` 打开工具  
2. 右侧侧栏改字段 / 上传立绘，左侧画布即时预览  
3. 点「导出 PNG」→ 下载 `char-{slug}.png`（1920×1080）  
4. 需要竖图时（第二期）再切画布比例并导出

---

## 3. 项目位置与技术栈

| 项 | 选择 |
|----|------|
| 路径 | `e:\quartash\char-card-studio\`（独立目录，不嵌主站） |
| 栈 | Vite + React + TypeScript |
| 样式 | 从主站 `CharactersTeaser` / `SectionTeaser.css` **拷贝并裁剪**人物相关层，不链主站源码 |
| 字体 | 拷贝或 CDN 引用现用像素字体（Fusion Pixel 等） |
| 导出 | `html-to-image`（或 `modern-screenshot`）对预览根节点 `toPng`，`pixelRatio` 按目标分辨率计算 |
| 状态 | React `useState`；立绘用 `URL.createObjectURL`；可选 `localStorage` 记住上次编辑（非必须，第一期可做） |

## 4. 界面结构

```
┌─────────────────────────────────────────────────────────┐
│  CHAR CARD STUDIO              [导出 PNG 1920×1080]      │
├───────────────────────────────────┬─────────────────────┤
│                                   │  中文名              │
│     16:9 预览画布（缩放适配）        │  英文名              │
│     视觉 ≈ 人物 Teaser 一屏         │  短简介              │
│                                   │  成员介绍（多行）      │
│                                   │  组织备注（侧栏用）    │
│                                   │  立绘上传             │
│                                   │  主题色（可选）        │
│                                   │  [重置为默认示例]      │
└───────────────────────────────────┴─────────────────────┘
```

- 预览区：内部固定逻辑分辨率 **1920×1080**，用 CSS `transform: scale()` 缩放到侧栏旁可视区域，导出时按未缩放节点光栅化，保证像素正确。  
- 侧栏与顶栏**不进入**截图范围。

## 5. 侧栏字段

| 字段 | 绑定预览 |
|------|----------|
| 中文名 | 底栏大字 |
| 英文名 | 底栏英文小字 |
| 短简介 | `://` 右侧摘要 |
| 成员介绍 | 左侧「成员介绍」正文（`\n\n` 分段） |
| 组织备注 | 仅侧栏显示；**背景装饰大字固定 `OASIAS`**（对齐现站） |
| 立绘 | 上传 PNG/WebP；同时驱动立绘层与主题色剪影 mask |
| 主题色 | CSS 变量（默认主站青强调色） |

默认示例：可用主站「赫柏 / baiyu」一类占位数据与一张示例立绘（用户可替换）。

---

## 6. 预览视觉（从主站迁入的层）

保留并简化为**静态一屏**（无切换动画）：

- 背景星空 / 暗底  
- `CHARACTER` 水印字  
- 组织徽标（可用 `/logo.png` 主题色 mask 占位）  
- `OASIAS` 中段大字  
- 剪影 + 立绘  
- 成员介绍块  
- 底栏黑遮罩：姓名 / `://` 简介  
- **不包含**：左右切人箭头、圆点、组织 Tab、「进入名册」CTA（出图用不到）

---

## 7. 导出规格

| 项 | 值 |
|----|-----|
| 格式 | PNG |
| 尺寸 | 1920×1080 |
| 文件名 | `char-{英文名 slug 或中文名}.png` |
| 质量 | 尽量保留透明度；星空底为不透明黑亦可 |

失败时（跨域字体/图片）：提示用户改用本地上传立绘；字体尽量同域加载。

## 11. 风险与对策

| 风险 | 对策 |
|------|------|
| html-to-image 对复杂 CSS mask/filter 兼容差 | 优先简化导出层；剪影可降级为同色剪影图；必要时换 `modern-screenshot` |
| 字体未加载导致导出缺字 | 启动时 `document.fonts.ready` 后再允许导出 |
| 画布缩放导致导出模糊 | 导出针对未缩放的 1920×1080 节点，不用屏幕截图像素 |
